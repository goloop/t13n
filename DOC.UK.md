## Ментальна модель

`t13n` (транслітерація) конвертує Unicode-текст в ASCII. Для кожної функції діють
три гарантії:

1. **Вивід — завжди чистий 7-бітний ASCII.** Що б не зайшло, вихід безпечний для
   URL, імен файлів і систем лише з ASCII.
2. **Нічого не панікує.** Приймається будь-який ввід, включно з невалідним UTF-8;
   незіставлені code points просто не дають виводу.
3. **Базова таблиця лінива й компактна.** Вона зберігається як вбудований ресурс
   і декодується при першому використанні, тож імпорт пакета дешевий.

Транслітерація виконується одним, ощадливим до алокацій проходом. Є два входи:
пакетні функції для разових викликів і повторно використовуваний `T13n`,
налаштований функціональними опціями для повторного вжитку.

```go
import "github.com/goloop/t13n/v2"
```

## Функції для цілого тексту

```go
func Make(text string) string
func Trans(l, text string) string
func Render(l, text string, ctr lang.TransRules) string
```

- `Make` транслітерує без регіональних правил.
- `Trans` застосовує правила мови `l`.
- `Render` — це `Trans` плюс кастомна функція правил (або `nil`).

```go
t13n.Make("こんにちは、みんな!")       // "Ko N Ni Chi Ha Mi N Na!"
t13n.Make("世界")                     // "Shi Jie"
```

## Окремі символи

```go
func String(c rune) string
func Rune(c rune) (string, bool)
```

`String` транслітерує один code point (повертає `""`, коли незіставлено). `Rune`
також повідомляє, чи існує зіставлення — `ok` хибний для незіставлених code
points на кшталт емодзі чи будь-чого поза Basic Multilingual Plane:

```go
s, ok := t13n.Rune('界') // "Jie ", true
_, ok = t13n.Rune('😀')  // "", false
```

## Мовні правила

`Trans`/`Render` беруть мову `l`. Передайте константу `lang` (наприклад
`lang.UK`, `lang.DE`, `lang.SL`) чи еквівалентний рядок (`"uk"`, `"de"`, `"sl"`);
використовуйте `lang.None` чи `""`, щоб пропустити регіональні правила:

```go
import "github.com/goloop/t13n/v2/lang"

t13n.Trans(lang.UK, "Доброго вечора, ми з України!")
// "Dobroho vechora, my z Ukrainy!"
```

Регіональні правила важливі, бо той самий символ транслітерується по-різному в
різних мовах — наприклад, українська й словенська рендерять той самий
кириличний текст по-різному.

## Кастомні правила

Кастомне правило виконується **після** мовних правил, дозволяючи пост-обробку
виводу — наприклад, щоб збудувати slug. Правило — це `lang.TransRules`:

```go
type TransRules func(TransState) (string, int, bool)
```

Воно повертає рядок-заміну, зсув (скільки наступних рун воно спожило, для
диграфів) і чи застосувалося. `TransState` дає контекст навколо:

| Поле | Зміст |
|------|-------|
| `Prev`, `Curr`, `Next` | попередня / поточна / наступна руна (`rune(0)` на краях) |
| `Value`        | запропонований переклад `Curr` |
| `IsBegin`      | `Curr` на початку слова |
| `IsApostrophe` | `Curr` — це апостроф між двома не-роздільниками |

```go
func slug(ts lang.TransState) (string, int, bool) {
    switch ts.Value {
    case " ", "_", "~":
        return "-", 0, true
    }
    return strings.ToLower(ts.Value), 0, true
}

t13n.Render(lang.UK, "Доброго вечора", slug) // "dobroho-vechora"
```

> Для справжніх slug'ів надавайте перевагу модулю `github.com/goloop/slug` — цей
> приклад лише ілюструє кастомні правила.

## Повторно використовуваний T13n

```go
func New(opts ...Option) *T13n

func WithLang(l string) Option
func WithRules(r lang.TransRules) Option
func WithFallback(f func(rune) string) Option
func WithStrictASCII() Option
```

`New` будує конфігурований, повторно використовуваний транслітератор. Після
налаштування він безпечний для конкурентного використання, тож будуйте раз і
діліться:

```go
uk := t13n.New(t13n.WithLang(lang.UK))
sl := t13n.New(t13n.WithLang(lang.SL))

text := "Отак подивишся здаля на москаля"
uk.Make(text) // "Otak podyvyshsia zdalia na moskalia"
sl.Make(text) // "Otak podivishsia zdalia na moskalia"
```

Сетери ланцюгові й взаємозамінні з опціями:

```go
func (t *T13n) Make(text string) string
func (t *T13n) Lang(l string) *T13n
func (t *T13n) Rules(r lang.TransRules) *T13n
func (t *T13n) Fallback(f func(rune) string) *T13n
func (t *T13n) StrictASCII() *T13n
```

```go
tr := t13n.New().Lang(lang.UK).Rules(slug)
```

`Fallback` задає функцію для обробки рун, які базова таблиця не зіставляє (замість
викидання); `StrictASCII` гарантує, що вивід містить лише ASCII, відкидаючи все,
що ним не було б.

## Ітерація

```go
func RunesSeq(l, text string) iter.Seq2[rune, string]
```

`RunesSeq` видає пари `(rune, транслітерація)` для `text` мовою `l`, тож можна
кермувати власним рендерингом, не матеріалізуючи весь результат:

```go
for r, s := range t13n.RunesSeq(lang.UK, "Київ") {
    fmt.Printf("%c -> %q\n", r, s)
}
```

## Рецепти й поради

**Будуйте один транслітератор на мову.** `t13n.New(t13n.WithLang(...))`
незмінний після налаштування й потокобезпечний — сконструюйте на старті й
використовуйте повторно, а не викликайте `Trans` із мовою щоразу.

**Виявляйте незіставлені code points.** Використовуйте `Rune` (не `String`),
коли потрібно знати, чи мав символ зіставлення, напр. щоб підставити заповнювач
для емодзі.

**Гарантуйте ASCII-вивід.** Додайте `WithStrictASCII()` (чи викличте
`StrictASCII()`), коли результат живить строго ASCII-приймач і ви радше
відкинете, ніж пропустите неочікуваний символ.

**Пост-обробляйте правилом.** Беріть `Render`/`Rules`, щоб зменшити регістр,
поміняти роздільники чи згорнути символи в тому ж проході — але використовуйте
модуль `slug`, коли справді хочете slug'и.

**Стрімте великий ввід.** `RunesSeq` дозволяє споживати транслітерацію ліниво,
пара за парою, замість побудови одного великого рядка.
